## 过程中发现、修掉的问题（真实记录，可以用在视频「交给 AI」那一段）
1. **事件驱动版的成本口径和向量化版不一致**。
   - 初稿的逐日循环，是按扣成本之前的资金去算目标股数；向量化版是按扣成本之后的资金算。两者每次调仓会差一点点，对账会失败。
   - 写对账检查之前读代码时发现了，统一改成「先扣成本，再按剩下的钱算股数」。
   - 改完以后，两个版本逐日资金的最大相对误差在 1e-14 量级。
2. 初稿里留了一行没用的代码（`uninvested = ... if False else None`），删掉了。
3. **股息在哪里**：数据里的 `dividend` 字段全是 0，但复权价和未复权价的比值每季度跳一次，说明分红已经算进复权价。所以回测用复权价，等于按总收益口径算；不用再单独加分红。
